# Ireland transport & mobility dashboard

An interactive dashboard showing how people in Ireland travel: modal shift, the passenger survey, urban vs rural living patterns, car ownership, public transport supply, kilometres travelled, and who commutes and how that has changed for the bus.

The figures come from Central Statistics Office (CSO) PxStat and National Transport Authority open data. The public transport services and person-km figures are estimates; the page's "Sources, definitions" section explains how they're made.

The site is plain HTML and JavaScript with no server and no sign-in, so it runs on GitHub Pages. You can also open `index.html` straight from disk.

## Files

| File | What it is |
|------|------------|
| `index.html` | The page: layout, filters, tabs and styles |
| `app_core.js`, `app_modal.js`, `app_survey.js`, `app_supply.js`, `app_groups.js` | Chart code (d3) |
| `dash-shim.js` | Small runtime for filters, redrawing and data access |
| `data/*.csv`, `data/ireland_counties.geojson` | Source data exported from the pipeline |
| `make_commute_groups.py` | Turns a CSO table F7122 export into `data/commute_groups.csv` (the "Who commutes & the bus" tab) |
| `data.js` | The same data packed for the page. Generated by `build_data.py`, so don't edit it by hand |
| `d3.min.js` | d3 v7.9 (ISC licence, see `d3-LICENSE.txt`) |

## Updating the data

1. Re-export from the pipeline:
   `python transport_dashboard.py --export-snapshot OUT D:\Ireland\CSO_PxStat`
   Alternatively, replace any CSV in `data/` with a new export that has the same columns.
   For the "Who commutes & the bus" tab, download CSO table F7122 as CSV and run
   `python make_commute_groups.py F7122.csv`.
2. Run `python build_data.py` to rebuild `data.js`.
3. Commit and push. GitHub Pages republishes within a minute or two, at the same link.

## Sharing a filtered view

Filters are stored in the address bar. For example, `?geo=County|Galway&mapmetric=Cars per 1,000 residents#modal` opens the page filtered to Galway on the Modal shift tab. Copy the address bar to share exactly what you're looking at.
